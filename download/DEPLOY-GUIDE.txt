# راهنمای انتشار آنلاین سایت مدیریت فیلم
# ================================================

## مراحل کلی
1. ساخت حساب در Turso (دیتابیس رایگان)
2. ساخت حساب در Vercel (هاست رایگان)
3. انتقال داده‌ها به Turso
4. تنظیم متغیرهای محیطی در Vercel
5. دیپلوی (انتشار) سایت

---

## مرحله ۱: ساخت دیتابیس Turso (رایگان)
1. به https://turso.tech بروید و ثبت‌نام کنید (با GitHub ساده‌تره)
2. وارد داشبورد شوید و یک دیتابیس جدید بسازید:
   - نام دلخواه بدهید (مثلاً movie-db)
   - لوکیشن را نزدیک‌ترین به خودتون انتخاب کنید
3. بعد از ساخت، روی دیتابیس کلیک کنید
4. تب "Connect" رو بزنید
5. گزینه "Create Auth Token" رو بزنید
6. یک توکن می‌ده بهتون - اون رو کپی کنید
7. URL اتصال رو کپی کنید (شبیه این: libsql://movie-db-username.turso.io)

آدرس نهایی DATABASE_URL شما این شکلی میشه:
libsql://movie-db-username.turso.io?authToken=your-token-here


## مرحله ۲: ساخت حساب Vercel (رایگان)
1. به https://vercel.com بروید و ثبت‌نام کنید (با GitHub)
2. بعد از ورود، آماده‌اید


## مرحله ۳: انتقال داده‌های فعلی به Turso
1. فایل deploy.bat رو اجرا کنید تا Vercel CLI نصب بشه:
   deploy.bat
2. وقتی Vercel ازتون سوال کرد، تنظیمات رو قبول کنید
3. حالا فایل زیر رو اجرا کنید (آدرس Turso رو جایگزین کنید):
   migrate-to-turso.bat "libsql://movie-db-username.turso.io?authToken=your-token"
4. صبر کنید تا داده‌ها منتقل بشن


## مرحله ۴: تنظیم متغیرهای محیطی در Vercel
دو راه دارید:

### راه الف: از طریق سایت Vercel
1. وارد https://vercel.com شوید
2. پروژه‌تون رو انتخاب کنید
3. به تب Settings بروید
4. بخش Environment Variables
5. این سه متغیر رو اضافه کنید:

   نام                         مقدور
   --------------------------------------------------
   DATABASE_URL                libsql://your-db.turso.io?authToken=xxx
   ADMIN_PASSWORD              رمز عبور دلخواه برای مدیریت
   NEXT_PUBLIC_DISABLE_FOLDER   true

### راه ب: از طریق خط فرمان
   vercel env add DATABASE_URL
   vercel env add ADMIN_PASSWORD
   vercel env add NEXT_PUBLIC_DISABLE_FOLDER

   (برای هر کدوم مقدار رو وارد کنید)

نکته مهم: ADMIN_PASSWORD رو حتماً یک رمز قوی بگذارید!
بدون این رمز، کسی نمی‌تونه وارد بخش مدیریت بشه.


## مرحله ۵: انتشار سایت
1. فایل deploy.bat رو اجرا کنید
2. صبر کنید تا بیلد تمام بشه (چند دقیقه)
3. بعد از اتمام، Vercel یک آدرس بهتون میده (مثلاً: https://movie-manager-xxx.vercel.app)
4. سایت شما آنلاین است!


## بعد از انتشار
- بازدیدکنندگان فقط لیست فیلم‌ها رو می‌بینند
- دکمه "باز کردن پوشه" نمایش داده نمیشه
- برای ورود به مدیریت، دکمه "مدیریت" رو بزنید و رمز عبور رو وارد کنید
- برای اپدیت سایت از لوکال:
  1. فیلم‌ها رو از طریق مدیریت آنلاین اضافه کنید
  2. یا از طریق مدیریت لوکال اضافه کنید و دیتا رو مجدداً منتقل کنید


## نکات مهم
- Turso رایگان: ۹ گیگابایت دیتابیس و ۲۵ میلیارد خواندن در ماه
- Vercel رایگان: ۱۰۰ گیگابایت ترافیک در ماه
- پوسترها: حتماً از URL استفاده کنید (آپلود لوکال آنلاین کار نمی‌کنه)
- دیتابیس لوکال شما دست‌نخورده باقی می‌مونه
